# Asset sources

All bundled files are stored locally so the simulation continues to work as a static GitHub Pages site.

## Human model

- `assets/models/human.glb`: CC0 rigged human by [Quaternius](https://quaternius.com), prepared for browser use by [UMRAM Bilkent University](https://github.com/UMRAM-Bilkent/supine-human-model). No attribution is legally required; credit is included as a courtesy.
- Full-resolution scan reference: [Human scan by Diana Liu / Thunk3D](https://sketchfab.com/3d-models/human-a75f10c50fb44a70a1b04bcb49f3d71f), licensed CC BY 4.0. This two-million-triangle source is linked but not bundled because Sketchfab requires an authenticated download and the original is not optimized for this static viewer.

## Environment captures

The bundled 1K HDR files are CC0 360-degree photographic environment captures from [Poly Haven](https://polyhaven.com). The app combines these real-world captures with interactive Three.js terrain, track, water, precipitation, lighting, and physiological feedback.

- `rower-snow.hdr`: [Lago d'Isola](https://polyhaven.com/a/lago_disola), Andreas Mischok
- `rower-fall.hdr`: [Lakes](https://polyhaven.com/a/lakes), Sergej Majboroda
- `rower-summer.hdr`: [Resting Place](https://polyhaven.com/a/resting_place), Sergej Majboroda
- `runner-desert.hdr`: [Goegap](https://polyhaven.com/a/goegap), Greg Zaal
- `runner-mountain.hdr`: [Alps Field](https://polyhaven.com/a/alps_field), Andreas Mischok
- `runner-humid.hdr`: [Farmland Overcast](https://polyhaven.com/a/farmland_overcast), Grzegorz Wronkowski
- `sprinter-rain.hdr`: [Overcast Soil](https://polyhaven.com/a/overcast_soil), Sergej Majboroda
- `sprinter-summer.hdr`: [Bloem Train Track Clear](https://polyhaven.com/a/bloem_train_track_clear), Jenelle van Heerden and Greg Zaal
- `sprinter-winter.hdr`: [Snowy Field](https://polyhaven.com/a/snowy_field), Andreas Mischok
